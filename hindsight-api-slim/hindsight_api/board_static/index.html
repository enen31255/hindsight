① 记忆工作台是什么

              
本机 Hindsight 记忆库（单库 coding-agent::dsh-brain）的可视面板：本页由 hindsight fork 自带（/ui，:8888），DSH 侧栏「记忆」入口即内嵌本页。数据与引擎同源直取，无代理层、不经旧 8899 看板。

              
与机器上另外三套记忆系统（hermes-loop、工作台知识库、本地 Hermes）互不读写。

            

            

              
② 数据从哪来

              
DSH 会话开始时 hook 自动把会话回写（retain）给 daemon（127.0.0.1:8888）→ 存入内嵌 PostgreSQL；LLM 提取走局域网 192.168.1.14:11438（Qwen3.6-35B），embedding/rerank 为本地模型不出网。

              
daemon 由 DSH hook 拉起，DSH 重启会带走它、下次会话自动重拉（离线横幅消失即恢复）。

            

            

              
③ 页面导览

              
    
                
  • 工作台：注意力区（失败/处理中/陈旧页/待归纳）、记忆存量 8 格、近 7 天写入节奏、用量按日、库档案。
    • 
                
  • 记忆检索：全部记忆条目 master-detail，类型/状态/标签/时间/关键词服务端过滤；右侧精确引用卡（节点 ID / 来源文档 / 血缘 / 复制引用）。
    • 
                
  • 观察流：observation 时间线（按日分组），scope 标签 chips + 关键词过滤，条目点击跳检索详情。

  • 实体图谱：实体共现图（Top-N + min_count 策略）+ 提及排行，点击实体跳按 entity_id 过滤的检索。

  • 知识页面：蒸馏页面树 + 陈旧徽标 + 本页/整包导出 + 版本历史卡（mental-models 快照）。

④ 召回实验室用法

              
budget 三档控制检索规模与耗时：low 实测 40–110s（页面超时 150s）、mid/high 更久更全；trace 展开可看召回轨迹。结果分数 = scores.final（rerank 与语义融合分）。非法 budget 会 422。

            

            

              
⑤ 设置页说明

              
    
                
  • 只有白名单字段可写：PATCH /banks/{id}/config，merge 语义（只发改动键）、整批原子（任一字段非法整批 400、零写入）、热生效无需重启。
    • 
                
  • 徽标「覆盖」= 本库覆盖项；无徽标 = 继承全局默认。倾向 disposition 选「继承默认」即发送 null 清除覆盖。
    • 
                
  • 保存 = 两步确认（逐字段 diff → 3 秒倒计时）；「回滚到最近保存」= 把最近一次成功保存时的全部覆盖项整包恢复。
    • 
                
  • 凭据 / LLM 模型 / 端口 / 数据库类是服务器级字段，引擎直接 400 拒绝（daemon 启动环境自管）；本页不会渲染它们。
    • 
                
  • 写通道被 env 关闭时（HINDSIGHT_API_ENABLE_BANK_CONFIG_API=false）本页降级只读并显示横幅。
    • 
              

            

            

              
⑥ 运行与队列 / 失败

              
operations = 后台 LLM 任务（retain 提取 / 归纳 / 页面刷新 / 图谱维护等）。failed 卡的 error_message 是引擎原文（如超 3600s 墙被取消，提示调 HINDSIGHT_API_REFLECT_WALL_TIMEOUT）。重试按钮当前只读（写通道未开放该端点）。

            

            

              
⑦ 口径与 FAQ

              
    
                
  • 主题：自动（跟随系统明暗）/ 浅色 / 深色，存 localStorage hsb-theme；本页跨源读不到 DSH 客户端变量，自动档只跟 OS。
    • 
                
  • 离线横幅：daemon 未运行——DSH 重启后 hook 会自动拉起，轮询恢复后自动解除。
    • 
                
  • 标签数字对不上：标签 chips 用 /tags 全库口径，记忆卡片过滤 total 是列表口径，两者本就不同。
    • 
                
  • 时序分桶：写入节奏按 UTC 自然日分桶（本地 08:00 封口），当天数字随时间增长属正常。
    • 
                
  • 灰按钮：写操作仅限设置页签白名单字段的 PATCH；队列重试、清库、导入等未开放端点的按钮恒灰。
    • 
              

            

            

              
⑧ 安全与版本

              
API 无鉴权、仅绑 127.0.0.1——本机信任环境使用，勿把 8888 暴露到局域网。引擎回滚 = uv tool install --force hindsight-api==1.2.3；禁止 uv tool upgrade hindsight-embed（官方新版会把 pg schema 顶上去，fork 版本回不去）。

              
版本：board_static fork（分支 hindsight-board）+ 引擎 /v1/version 自报（见顶部状态带「兼容性」）。
